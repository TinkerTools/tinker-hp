75 ! "erfcore" evaluates erf(x) or erfc(x) for a real argument x;
76 ! when called with mode set to 0 it returns erf, a mode of 1

81 !
82 ! W. J. Cody, "Rational Chebyshev Approximations for the Error
83 ! Function", Mathematics of Computation, 631-638, 1969
84 !
85 ! adapted from an original program written by W. J. Cody,
86 ! Mathematics and Computer Science Division, Argonne National

90 !

93 ! a conservative value is the largest machine number
94 ! X such that 1.0 + X = 1.0 to machine precision
95 !
96 ! xbig largest argument acceptable for erfc; solution to
97 ! the equation: W(x) * (1-0.5/x**2) = XMIN, where
98 ! W(x) = exp(-x*x)/[x*sqrt(pi)]
