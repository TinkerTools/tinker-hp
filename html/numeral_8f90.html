subroutine numeral ( integer  number,
character*(*)  string,
integer  size

converts an input integer number into the corresponding right- or left-justified text numeral

Parameters
[in]number,:integer value of the number to be transformed
[in]string,:text string to be filled with corresponding numeral
[in]size,:on input, the minimal acceptable numeral length, if zero then output will be right justified, if nonzero then numeral is left-justified and padded with leading zeros as necessary; upon output, the number of non-blank characters in the numeral
