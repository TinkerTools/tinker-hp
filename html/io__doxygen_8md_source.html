1 # I/O and Tinker-HP 
2 
3 **I/O of trajectories** works as in Tinker 8: if no keyword is specified
4 then frames will printed individually at the selected frequency. By
5 adding the keyword **archive** then the frames will be directly appended
6 in an \*.arc file.
7 
8 Moreover, Tinker-HP also supports **CHARMM dcd format**: adding the line
9 **dcdio** to the keyfile will print a trajectory with the dcd format.
10 When running the analyze or the bar postprocessing programs, if
11 **dcdio** is specified in the key file, then the programs will look for
12 the associated \*dcd file and process the frames it contains.
13 
14 
15 Other keywords control the writing of some quantities during a molecular dynamics trajectory:
16  - SAVE-VELOCITY: print velocities in a separate file
17  - SAVE-FORCES: print forces in a separate file
18  - SAVE-INDUCED: print induced dipoles in a separate file
19  - PBC-UNWRAP: print unwrappped trajectory, without this keywords atoms are wrapped by molecules
20 
21 
22 Tinker-HP deals with restart files for dynamic trajectories the same way
23 as Tinker-8 does by creating a \*.dyn file encompassing current
24 positions, velocities and accelerations of the system.
