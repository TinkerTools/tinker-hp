searches an input string for the first alphabetic character (A-Z or a-z); the region from this first character to the first blank space or separator is returned as a "word"; if the actual word is too long, only the first part is returned

Parameters
[in]string,:input character string to be searched
[in]word,:output with the first word in the string
[in]next,:input with first position of search string; output with the position following word
