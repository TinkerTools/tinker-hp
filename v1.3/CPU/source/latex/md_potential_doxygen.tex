Various bonded and non-\/bonded energy terms are implemented with analytical gradients in Tinker-\/\-H\-P. Parameter files associated to well established force fields such as charmm22, ambers99 or amoeba can be found in the parameters directory of the repository.

Information about coupling of the G\-P\-U version of Tinker-\/\-H\-P with machine-\/learning libraries in order to run simulations leveraging machine learning potentials can be found \href{md_Deep-HP.html}{\tt here}.
